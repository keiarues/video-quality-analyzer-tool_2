# キーボードショートカット検討

2026-11-17時点の検討案。キー割り当ては未決定で、実装・実操作検証はまだ行っていない。

## 対象と現状

- 完成版仕様書には再生・停止・シーク・前後1秒／5秒・1コマ移動などの操作があるが、キー割り当ての規定はない。
- 主画面の再生ボタン、シークバー、一覧、メニュー、比較タブを対象とする。範囲設定やグループ設定などのダイアログでは、まず標準のTab・Space・Enter・Esc操作を維持する。
- 現在、主画面にアプリ共通のキー割り当てはない。グラフ境界のThumbにフォーカスがある場合だけ、上下矢印で高さを10ずつ変更する。シークバーなどの標準部品にも固有のキー操作がある。

## 初期候補

| 操作 | キー案 | 条件・理由 |
| --- | --- | --- |
| 再生／一時停止 | Space | 動画操作の中心。ボタン、チェックボックス、一覧などにフォーカスがある場合は、その部品の標準操作を優先する。 |
| 停止して先頭へ戻る | 未定 | Ctrl+Shift+Sは一般的な「名前を付けて保存」と衝突するため避ける。 |
| 1秒戻る／進む | Ctrl+Left／Ctrl+Right | シークバーや文字入力欄の標準操作より、フォーカスがある部品を優先する。 |
| 5秒戻る／進む | Ctrl+Shift+Left／Ctrl+Shift+Right | 1秒移動との対応をそろえる。文字選択操作との衝突に注意する。 |
| 1コマ戻る／進む | 未定 | JIS配列とUS配列の両方で押しやすく、入力欄と衝突しない組み合わせを試す。 |
| 動画ファイルを追加 | Ctrl+O | 一般的な「開く」の操作。ファイル選択画面を開く。 |
| ミュート切り替え | Ctrl+M | 音量スライダーのキー操作とは分ける。 |

評価開始／中止、評価クリア、動画削除、CSV出力、グループ変更には初期段階でグローバルキーを割り当てない。時間のかかる操作や結果・登録内容を変える操作は、画面上の操作と確認手順を先に確かめる。

## 入力の優先順位

1. ダイアログ、メニュー、コンボボックス、テキスト入力、一覧、スライダー、チェックボックス、タブ、ボタンなど、フォーカス中の部品の標準キー操作を優先する。
2. 主画面にフォーカスがあり、対象操作が有効なときだけショートカットを実行する。無効なときは実行せず、例外や状態変更を発生させない。
3. IMEによる日本語入力中、修飾キーの組み合わせやキーの自動反復は、各操作に適した扱いを専用テスト画面で確認する。シークの連続要求では最後の位置を優先し、現在の再生／一時停止状態を維持する。
4. 比較表示と通常プレビューで同じ操作を同じキーに割り当て、既存の共通再生操作を呼ぶ。左右の共通時刻、評価した部分のみ再生の区間制約も既存処理に従う。

## 実装前に決める点

- Spaceをどのフォーカス範囲で有効にするか。特に一覧選択中と映像表示中の操作感を確認する。
- 停止と1コマ移動のキー案。
- メニューとボタンのツールチップにキーを併記する範囲。割り当てを確定したものだけ表示する。

## 検証の進め方

1. 専用テスト画面でキー判定とフォーカス優先順位を確認する。文字入力、一覧、シークバー、グラフ境界、比較タブ、IME入力中を含める。
2. 再生・一時停止・停止・秒移動・コマ送りを通常プレビューと比較表示の両方で確認し、連続入力でも最後のシーク要求が残ることを自動検証する。
3. 正常動作を確認してから主画面へ組み込み、ツールチップとメニュー表示を更新する。実キー操作の目視確認範囲と自動確認範囲を分けて記録する。
