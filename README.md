# VideoQualityAnalyzer

Windows向けの動画品質比較ツールです。元動画と圧縮後の動画を並べて再生し、映像の違いや品質評価結果を確認できます。

**公開バージョン：v1.2.0**

## 主な機能

- **動画の比較表示**：2画面、ワイプ、差分ヒートマップを切り替えて比較
- **再生操作**：再生・一時停止・シーク・コマ送り、左右の拡大縮小と表示位置の同期
- **品質評価**：VMAF・SSIM・PSNRの計算、品質推移とビットレートのグラフ表示
- **CSV出力**：フレームごとの評価値と動画ごとの平均値を、Excelでグラフ化できる形式で保存
- **動画の整理**：グループ設定、一覧の並べ替え、フォルダーのドラッグ＆ドロップによる登録

## 起動方法

1. 配布ファイルを展開し、`VideoQualityAnalyzer.exe` を起動します。
2. FFmpegが見つからない場合は、設定画面が自動的に開きます。
3. 「ffmpegを取得」、または「フォルダーを選択」でFFmpeg・FFprobeを指定してください。
4. 設定を保存してアプリを再起動します。
5. 比較する動画を追加し、基準動画と比較動画を選択します。

## 基本的な使い方

1. 「追加」、またはファイル・フォルダーのドラッグ＆ドロップで動画を登録します。
2. 元動画を基準動画に設定し、比較する動画を選択します。
3. 「2画面」「ワイプ」「差分ヒートマップ」を切り替え、再生やコマ送りで映像の違いを確認します。
4. 品質を数値で比較する場合は、VMAF・SSIM・PSNRから使用する指標を選択し、「評価を開始」を押します。
5. 評価結果をグラフで確認し、必要な結果をCSVへ出力します。

## 対応環境・制限事項

- Windows x64向けです。開発・検証はWindows 11で行っています。
- 動画の読み込みや品質評価にはFFmpeg・FFprobeが必要です。
- 比較表示は、同じ解像度・同じフレームレートのCFR（固定フレームレート）動画を対象としています。VFR（可変フレームレート）・異解像度の比較は未対応です。
- 現在も開発中のため、動画の形式や利用環境によって正常に動作しない場合があります。
