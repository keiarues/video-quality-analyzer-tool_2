# C#・WPF版 実装状況

更新日: 2026-11-03

[完成版仕様書](CSharp_WPF_仕様書.md)を基準とした実装状況。仕様の追加ではなく、作成済みの範囲と残りを記録する。

## 今回追加した機能

- 比較画面で2画面・ワイプ・ヒートマップを切り替える。全モードで同じFFmpeg復号画像を使う。
- 品質評価専用画面からVMAF・SSIM・PSNRを選択して実行する。進捗時間、中断、完了結果の再利用、全結果リセットに対応する。
- 完了結果は主画面の実行中メモリに保持する。元動画変更・削除で依存結果を破棄し、比較動画削除でその動画の結果を除去する。
- フレーム品質推移と平均品質対ビットレートのグラフを表示する。平均値のグラフは評価済みの全比較動画を対象とし、選択動画の点を強調する。同じグループの点を一覧順に結ぶ。クリックでシーク・動画選択を行う。
- 動画単位・フレーム単位のCSVをUTF-8 BOM付きで保存する。ビットレートはファイルサイズと長さからの換算値と明示する。フレーム時刻は現在のCFR対象範囲で平均fpsから換算する。
- 比較動画のグループを一括設定・解除する。一覧を登録順・動画名順・グループ順に並べ替える。

## 自動確認した範囲

成功した確認手順はリポジトリ直下の `tools/Run-FeatureChecks.ps1`。

- Releaseビルド：警告0、エラー0。
- `tests/Run-Tests.ps1 -NoRestore`：22件合格。既存15件に品質ログ集計、CSV、グループと一覧順の7件を追加。
- 短い生成動画の実計算：同一動画SSIMが1、異なる動画のSSIM・PSNR・VMAFが各30フレーム。開始前と実行途中の中断を確認。
- 専用グループ設定画面：適用操作と結果を自動確認してから本体へ接続。
- 専用評価画面：SSIM・PSNRの実行、完了結果の再利用、グラフの線と点の生成を自動確認。
- 主画面：並べ替え後の選択維持、登録順復元、元動画変更・比較動画削除・元動画削除時の評価結果破棄、アプリ終了まで自動確認。終了時の診断ログ待ちで画面が停止する問題も修正。
- 本体に組み込んだ比較画面：配置済み動画6組で一時停止・再開・シーク後の左右対応と、2画面・ワイプ・ヒートマップの切り替えを自動確認。

これらは再生性能の再判定ではない。人による画面レイアウト・クリック操作・CSV保存ダイアログの確認、実動画全組での品質評価は今回の自動確認に含まない。

## フレーム比較の主画面への統合（2026-11-04）

- 比較処理を再利用可能な `ComparisonPanel` へ分離し、主画面の映像領域へ埋め込んだ。独立した `ComparisonWindow` は既存の専用検証用として同じ部品を使用する。
- 通常利用で別ウィンドウを開くボタンを削除。共通の一覧選択、再生、一時停止、停止、シーク、秒移動、コマ送りを比較部品へ接続した。表示タブと専用オプションは映像領域内に配置する。
- 一覧変更は現在位置を引き継ぎ、再生中なら新しい組で再開する。連続変更では古い取得処理をキャンセルする。比較対象から外れる際は復号器と画像を解放し、1本表示へ戻る。
- 同解像度・同fpsのCFR2本で比較部品を使用し、それ以外は従来の共通FFmpegプレビューを維持。音声も既存の左音声経路を使い、対応範囲は拡張していない。配置済み操作試験素材は音声なしのため、音声同期は今回未検証。
- 6組の主画面操作で再生・タブ切り替え・一時停止保持・1コマ送り・静止復号との左右画素一致・停止時の先頭保持を自動確認。連続選択と1本表示への切り替え、比較処理の解放も確認する。`tools/Run-FeatureChecks.ps1` に `--verify-main-comparison` を追加した。
- Releaseビルドは警告0・エラー0、MSTest25件合格。専用比較画面の既存6組も合格。主画面の描画画像で組み込み配置を確認した。追加の性能ベンチマークは実施していない。

## 再生制御の配置とボタン（2026-11-04）
