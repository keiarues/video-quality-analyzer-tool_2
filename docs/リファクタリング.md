# リファクタリングの進捗と次の対象

更新日: 2026-11-17

## 今回整理した範囲

- `MainWindow.xaml.cs` は状態と初期化、起動時の検証振り分け、終了処理を担当する。約1,077行から149行になった。
- `MainWindow.Library.cs` は動画の登録・削除、一覧、グループ、並べ替え、選択、ファイルドロップを担当する。
- `MainWindow.Playback.cs` は左右スロットの開閉、再生・停止・コマ送り・シーク・音量操作を担当する。
- `MainWindow.PlaybackStatus.cs` は共通再生時刻、表示更新、性能とフレーム位置の表示を担当する。
- `MainWindow.StartupVerification.cs` は起動時の画面検証3件を担当する。

主画面の分割ではメソッドと状態の動作を変えていない。`partial` の共有状態は残っており、ファイル間の依存はまだ強い。

- 各コード変更後のReleaseビルドは警告0・エラー0。
- 各コード変更後の `tests/Run-Tests.ps1 -NoRestore` は57件合格。

1. `QualityGraphPanel.cs` の長いコンストラクタを、描画、凡例、入力操作、画面検証ごとに整理する。現在はローカル関数とラムダが相互に状態を共有するため、先に必要な状態を明示してから小さく切り出す。
2. `MainWindow.Library.cs` と `MainWindow.Playback.cs` の境界にある選択変更時の再生維持を、専用の状態・操作として整理する。左右共通時刻、古い非同期結果の破棄、右音声消音の既存動作を検証する。

分割だけでは総コード量は大きく減らない。今後は変更対象のファイルを狭め、重複した計算や状態管理を確認できた範囲で共通化する。
