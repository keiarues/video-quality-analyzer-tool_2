# コマンドによる自動テスト

MSTest 4.0.2を導入。画面認識・マウス操作・動画素材なしで実行する。

## 実行

リポジトリ直下で以下を実行する。初回はNuGetへの接続が必要。

```powershell
.\tests\Run-Tests.ps1
```

取得済みパッケージでの実行:

```powershell
.\tests\Run-Tests.ps1 -NoRestore
```

終了コード0は合格、それ以外は失敗。スクリプトは新しいTRXの作成と、1件以上の実行・全件合格も確認する。詳細はコンソールと`VideoQualityAnalyzer.Tests/TestResults`のTRXに出力する。
テスト用NuGet.Configだけでnuget.orgを有効にし、通常アプリの取得先設定は維持している。

## 対象

- 空の動画一覧、基準動画・比較動画の選択、直前の右動画維持、不正なID、世代番号の引き渡し。
- 診断ログの終了時書き出し、実行ID、性能値、提示fpsの未測定記録。

既存のSmokeとMediaFoundationProbeは引き続き素材・デコード検証に使用する。
今回のテストは実際の再生、非同期競合、左右同期精度、音声消音、GPU提示、実提示fps、画面レイアウトを検証しない。これらの達成を示すものではない。

## 検証記録（2026-10-30）

`Run-Tests.ps1 -NoRestore`で10件合格、失敗・スキップ0件。警告なし。Codexの制限付き実行ではテストが終了せず、制限外の実行で正常終了を確認した。停止対策として60秒のハング検出を設定している。
新しいテストはこのプロジェクトに追加し、AIは通常、終了コードと結果要約を確認する。失敗時に必要な詳細を読む。

## 完成版機能の確認（2026-11-03）

`tools/Run-FeatureChecks.ps1` でReleaseビルド、MSTest、3指標の実計算と中断、グループ設定画面、評価結果再利用とグラフ描画、比較画面6組の操作をまとめて確認する。比較試験には配置済み5本の動画と可視のWindowsデスクトップが必要。MSTestは22件。

品質評価の実計算は生成した64×64・30フレームのFFV1動画を使う。全動画・長時間の品質評価試験や、マウスによる画面操作・CSV保存ダイアログの目視試験を代替しない。追加の性能ベンチマークは実施しない。
