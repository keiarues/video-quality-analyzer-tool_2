# VideoQualityAnalyzer v1.3.0 リリースノート

公開日：2026年11月18日

v1.2.0からの主な変更は、動画の一部を対象にした品質評価、評価区間だけの再生、表示スタイルの選択、品質グラフのPNG保存です。

## 新機能

- **部分評価**：従来の全編評価に加え、時間範囲指定、周期的な区間指定、動画全体への均等配置から範囲を選べます。「評価範囲を設定」で対象フレームとVMAF・SSIM・PSNRを確認して評価を開始できます。結果の平均値、グラフ、CSVには選択した条件を反映し、グラフでは未評価区間を線でつなぎません。
- **評価した部分のみ再生**：完了済みの部分評価結果がある動画では、再生画面のチェックボックスから評価区間だけを左右同時に再生できます。未評価区間を飛ばし、シークやコマ送りも評価区間に合わせます。
- **表示スタイル**：設定画面で `None`、`System`、`Light`、`Dark` を選べます。設定ファイルがない場合の既定値は `System` です。変更は次回起動時に反映します。
- **グラフのPNG保存**：「ファイル」メニューから品質グラフを画像として保存できます。保存画面で対象グラフ、評価指標、画像サイズ、フォント、表示倍率、画像のライト／ダーク配色を選べます。既定の画像サイズは1024×768、画像の配色はライトです。

## 操作と表示の改善

- 評価範囲と評価指標の選択を専用画面にまとめ、評価対象の動画名を表示するようにしました。
- 明色・暗色それぞれの画面、プレビュー、グラフの配色を調整しました。選択中のタブには背景と輪郭線を付け、ボタンや入力欄の寸法・間隔も揃えました。
- CSVには部分評価の条件、集計フレーム数、評価方式を記録します。評価中のグラフ位置は、スキップした区間を含む元動画上の時刻で表示します。
- 動画の連続登録や切り替えで、古い読み込み結果や失敗通知が新しい選択に反映されないようにしました。

## 対応範囲と既知の制限

- 比較表示と部分評価は、同じ解像度・同じフレームレートのCFR動画を対象とします。VFR動画や異なる解像度の動画の比較には対応していません。
- 評価結果はアプリの起動中だけ保持します。アプリを閉じた後の結果復元には対応していません。
- 評価区間の切り替え時には読み込み待ちが生じる場合があります。実音声出力の区間境界と同期、物理画面での実提示fpsは未測定です。
