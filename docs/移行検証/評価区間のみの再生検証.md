# 評価区間のみのプレビュー再生

2026-11-16。専用画面で区間再生を確認してから、通常画面の再生UIに「評価した部分のみ再生」を追加した。初期状態はOFF。

## 区間と再生経路

`EvaluatedPlaybackPlan`で0始まり・終端を含まない元フレーム区間を保持する。シーク・順逆コマ送り・再生が同じ区間規則を使う。呼び出し側の配列変更では計画が変わらないようコピーする。

通常画面は、現在の評価条件と表示中の動画に対して、再利用可能な完了済み部分評価がある場合だけ有効化する。参照動画以外の表示動画全てに完了結果が必要。計算途中・失敗結果・旧方式・非表示の別条件の結果を区間の根拠にしない。現在の左右動画の共通範囲で区間を切る。

比較再生のフレームループが区間終端を検出し、次の区間の番号から左右の連続復号器を開き直す。未評価フレームは提示前に排除する。区間ごとに再生時計を起点へ戻し、読み込み待ちの時間を「遅延」として追い付こうとしない。通常再生ではこの制限を付けない。

区間切り替え時は左音声を一時停止・シークし、次の映像フレーム通知で再開する。右音声は既存どおり消音する。MediaElementを短い周期でシークして再生を作る方式ではなく、区間の切り替え時だけ位置を変更する。

チェック変更と動画変更では旧再生・旧静止読み込みを中止し、古い非同期結果で新しい表示を上書きしない。未評価動画への変更、全編条件への切り替え、評価結果クリアではチェックを解除し、再生中なら停止する。

## 操作

| 操作 | ON時 |
| --- | --- |
| 再生 | 現在の評価位置から。再生完了後は最初の評価区間から再開 |
| 停止 | 最初の評価フレームへ戻る |
| 一時停止 | 現在の評価フレームを維持 |
| コマ送り・戻し | 未評価フレームを飛ばし、前後の評価区間へ移動 |
| シークバー・グラフ | 次の評価区間へ合わせる。終端より後は最終評価フレーム |
| 秒戻し | 未評価位置なら前の評価区間の最終フレーム |
| OFF | 現在位置で制限を外し、通常再生・シークへ戻る |

プレビューの時間軸・品質グラフは元動画の時間軸のまま。評価区間を連結した新しい動画や音声ファイルは作らない。

## 検証

`tools/Run-EvaluatedPlaybackTests.ps1 -Main -Real`を実行した。Releaseビルドは警告0・エラー0。

専用画面では同じ比較パネルに時間範囲・周期・均等配置を設定し、FrameShownで通知された元番号を記録した。全フレームが設定区間内で、各区間を通過し、最終評価フレームで終了した。終了時の左右の画素を静止復号と照合し、一時停止と制限解除後のシークも確認した。

通常画面ではSSIMの部分評価を実際に完了させてチェックを有効にし、同じ3方式で以下を確認した。

- 未評価フレームの提示要求0、各区間の通過、最終評価フレームで停止。
- 終了後の再開、停止時の先頭移動、順逆コマ送り、グラフからの区間外シーク。
- 再生中のON/OFF、OFF後の任意位置への通常シーク。
- 左右どちらかを未評価動画に変更した場合の無効化・停止、評価済み動画へ戻した場合の利用可否。
- 全編条件への切り替えと結果クリアによる無効化。
- 2画面・ワイプ・差分ヒートマップで同じ区間制限が働くこと、右消音が維持されること。

生成素材は3秒・30fps・64×64のFFV1（音声あり）とH.264、未評価動画のコピー。実素材はFFV1元動画とAV1 QVBR32・H.265 ICQ28、1440×1080・30000/1001fps。時間範囲は0.2～0.6秒、周期は生成1秒・実素材100秒ごとに0.2秒、均等配置は0.2秒×3区間。実素材は比較可能な8,977フレームの範囲を使う。

| 素材 | 時間範囲の通知フレーム数 | 周期 | 均等 | 未評価フレーム |
| --- | ---: | ---: | ---: | ---: |
| 生成H.264 | 12 | 18 | 18 | 0 |
| AV1 | 12 | 16 | 17 | 0 |
| H.265 | 12 | 16 | 17 | 0 |

分数fpsのため、0.2秒の各区間が必ず6フレームになるわけではない。正確な区間と通知番号は[検証データ](評価区間再生データ/2026-11-16/)に保存した。通知はWPFへの更新要求の観測であり、物理画面の全フレーム提示・実提示fps・欠落率3%合格を証明する試験ではない。

## 回帰・最終確認

- `tools/Run-MainPartialEvaluationTests.ps1 -ShorterComparison`：全編・部分評価3方式、旧結果の再計算・再利用、中止、グラフとCSVが合格。
- 通常画面の実行ファイルへ`--verify-comparison=150`を指定し、FFV1＋AV1、FFV1＋H.265のチェックOFF相当の通常比較操作を確認。初回復号器の引き継ぎ、停止中・再生中シーク、一時停止・再開、静止復号画素の照合が合格。
- `tests/Run-Tests.ps1 -NoRestore`：57件実行・57件合格。区間の終端・順逆コマ送り・不正区間・呼び出し側の変更からの保護を3件追加した。既知のテストホスト接続問題を避け通常環境で実行。
- 通常画面の保存画像で再生UIのチェックボックスの配置を確認した。マウス操作による試験は行っていない。

実音声出力のサンプル単位の区間境界・音声同期は未測定。区間境界で復号の読み込み待ちが入ることがある。次の作業候補は、実使用時の区間切り替え待ち時間や音声境界を測り、必要なら先読みを検討すること。
