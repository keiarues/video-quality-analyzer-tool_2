# 動画品質アナライザー C#・WPF版 仕様書

更新日: 2026-11-03  
状態: 大まかな仕様を定めた初版。画面配置や細かな動作は今後随時修正する。

## 1. 目的と文書の位置づけ

元動画と複数のエンコード済み動画を登録し、映像の比較、品質評価、グラフによる確認、CSV出力を行うWindows用デスクトップアプリを作る。

本書は、C#・WPF版の完成版に向けた仕様を定める。記載した機能がすべて実装済みであることを示すものではない。

- [移行検証仕様書](移行検証/CSharp_WPF_移行検証_仕様書.md)などは試作・検証の経緯を残す資料とする。今後の完成版の方針について食い違う場合は、本書を優先する。
- 細部は必要になった時点で決める。先回りして対応条件や追加機能を増やさない。

## 2. 確定した開発方針

- C#・WPFへの移行は決定済みとする。
- 現在のプレビュー試作で性能は合格とする。当面、追加の性能向上や移行判定のためのベンチマークを作業目標にしない。この判断は、過去の未測定項目を測定済みとするものではない。
- 配置済みのテスト動画をすべて再生できる方式を優先する。動画の種類によって再生方式が変わり、色や見た目に差が出ないよう、すべての動画で統一した再生・表示経路を使うことを優先する。
- 具体的な再生方式は、この方針に合わせて設計時に決める。GPU方式への統一は前提にしない。
- Windows 11 / x64 / .NET 10 / WPFを対象とし、日本語UIとする。

## 3. 動画の登録と管理

- 元動画1本と複数の比較動画を登録する。複数ファイルの追加とドラッグ＆ドロップに対応する。
- 最初に登録した動画を元動画とし、登録後に元動画を変更できる。
- 比較動画の複数選択、一覧の並べ替え、グループ設定、削除を行える。
- 元動画を変更した場合は、その元動画に依存する評価結果を破棄する。
- 動画情報の取得中も画面を操作できるようにする。

## 4. プレビューと比較表示

- 「2画面」「ワイプ」「差分ヒートマップ」を切り替えて表示する。
- 当初の比較対象は、現在のテスト動画と同様、同解像度・同フレームレートのCFR動画とする。VFRや異なる解像度への対応は後から検討する。
- 左右は共通の再生位置を基準に扱い、比較表示では同じ元フレーム番号を対応させる。
- 一覧の選択による左右の表示対象は次の規則に従う。選択なしは元動画と先頭または直前の右動画、比較動画1本の選択は元動画とその動画、2本以上の選択は一覧順の先頭2本とする。
- 再生、一時停止、停止、シーク、前後1秒・5秒移動、1コマ移動、表示倍率、左右同期スクロールを用意する。
- 音声は左側の動画だけを再生し、音量とミュートを用意する。
- 動画の切り替え時は現在位置を引き継ぎ、連続操作では最後の選択を反映する。
- ワイプは映像上の境界を動かして比較する。ヒートマップは現在の試作の差分強調を基本とする。

## 5. 品質評価

- FFmpegを用いてVMAF・SSIM・PSNRを評価する。
- 比較動画と指標を選択し、全編または部分評価を行う。部分評価は時間範囲指定・周期的な区間指定・全体に均等配置の3方式とし、[部分評価](部分評価.md)に従う。
- 進捗と途中結果を表示し、評価を中断できる。
- 完了済みの動画・指標・評価条件の組み合わせは再利用する。条件が異なる結果は分けて保持する。中断・失敗した途中結果は完了済みとして扱わない。
- 評価結果をリセットできる。
- 計算と集計の規則は実装時に明示する。

## 6. グラフとCSV

- 指標別にフレームごとの品質推移と、平均品質対ビットレートを表示する。
- 動画の選択やグループをグラフへ反映する。
- グラフからプレビュー位置や比較動画を選べるようにする。
- 評価結果のフレームグラフまたはファイルグラフを保存前にプレビューし、PNG画像として保存できるようにする。選択中の指標・動画とグループを反映する。
- 動画単位・フレーム単位の2種類のCSVをUTF-8 BOM付きで出力する。
- CSVの列、対象範囲、書式は[品質CSV出力仕様](品質CSV出力仕様.md)に従う。

## 7. 設定と保存

- フォント、FFmpegの場所など、利用に必要な設定を保存する。
- 当初は動画一覧・評価結果・グループを起動間で復元しない。
- 診断ログとWindows向けポータブル配布を用意する。

## 8. 当面含めない機能

- 点滅比較
- 自動エンコード
- 解像度・フレームレート・色空間の自動補正
- 比較セットや評価結果のプロジェクト保存

## 9. 実装の進め方

統一したプレビュー経路を整理したうえで、動画管理、品質評価、グラフ、CSV・設定などを順次実装する。新機能は専用テスト画面で動作を確認してから本体へ組み込む。細かな画面構成や例外時の操作は、各機能を作る段階で本書へ追記する。
