# 部分品質評価テスト画面

専用画面で3方式の部分評価を検証する。本体画面の全編評価結果とは共有しない。

## 起動と操作

リポジトリ直下の `部分評価テストを起動.cmd` を実行する。

1. 元動画と比較動画を選ぶ。同解像度・同fpsのCFR動画を使用する。
2. 説明・評価区間バー・フレームステータスが付いたカードで方式を1つ選ぶ。選択カードは枠とチェック印で示し、下には選択した方式の設定欄だけを表示する。方式を切り替えても各入力値は保持する。元動画や入力値を変更すると、非選択カードも含めてバーとステータスを更新する。
3. 「対象区間を確認」で対象の秒数・元フレーム番号・フレーム数を確認する。
4. 指標を選択して「部分評価を実行」する。実行中は設定を固定し、中断できる。

## 区間の規則

- 時間範囲指定：開始秒以上、終了秒未満のフレームを評価する。
- 周期的な区間指定：0秒を基準に各周期の先頭から指定秒数を評価する。末尾区間は動画末尾まで。
- 全体に均等配置：先頭と末尾を含め、区間の開始位置を等間隔にする。1区間なら動画中央。区間長×区間数が動画長を超える指定は受け付けない。
- 時刻からCFRフレーム番号へ変換する。元動画の0始まりフレーム番号を保持し、隣接・重複区間は統合する。空の区間は除外する。
- 区間数の上限は1000。動画範囲外・不正数値・VFR推定動画は受け付けない。

## 結果と制限

- VMAF・SSIM・PSNRに対応し、初期選択はSSIM。
- 平均値は評価対象だけの値。従来と同様、PSNRの無限大は集計対象外となり、全フレームが無限大なら集計不能と表示する。
- FFmpegで左右に同じフレーム選択を適用し、評価ログの番号を元フレーム番号へ戻す。区間外も復号が必要になるため、対象削減率と速度向上率は一致しない。時間短縮率は未測定。
- 結果は画面内の表示のみ。全編評価のキャッシュ・グラフ・CSVとは接続しない。
- 未評価区間を飛ばすプレビュー再生、追加評価、結果の永続保存は未実装。

## 自動検証

`tools/Run-PartialEvaluationTests.ps1` は空白・日本語を含むパスに3秒・30fpsの生成動画を用意し、専用画面の3方式を自動実行する。同一動画のSSIM、評価対象フレーム数、元番号列とカードの排他選択・設定欄の切り替え・入力値の保持を検証する。各方式の描画画像を `measurement-results/partial-evaluation/screen-TimeRange.png`、`screen-Periodic.png`、`screen-Uniform.png` に保存する。

MSTestでは区間の端数・終了境界・周期末尾・均等配置・単一区間・不正設定を確認する。

## 評価区間バーとフレームステータス（2026-11-15）

- カードの固定模式図・設定例を廃止し、元動画の情報と各方式の現在の設定から評価対象を表示する。元動画のパス変更時は情報を取得し直す。連続変更では前の取得を中断し、古い結果を反映しない。
- バーの横幅全体を元動画の全フレーム数とし、評価する元フレーム番号の区間を正確な比率で描く。端数フレーム・終了を含まない境界・動画末尾の切り詰め・隣接区間の統合は実評価と同じ区間計算を使用する。
- 時間範囲指定：`00:00:05 ～ 00:01:00 1650フレーム` の形式。元フレーム境界に対応した時刻を表示し、端数があればミリ秒を付ける。時は24時間で折り返さない。
- 周期的な区間指定：`60秒ごとに10秒 3区間 750フレーム` の形式。区間数は末尾を含む実際の評価区間数。
- 全体に均等配置：`10秒 6区間 1800フレーム` の形式。隣接区間が統合される設定では統合後の区間数を示す。
- 上記の周期・均等配置の例は125秒・30fps・3750フレームを基準とする。全カードとも下段に表示し、長い文字列は折り返す。
- 動画未選択・取得中・取得失敗・不正設定ではバーを消去して状態を表示する。設定の詳細なエラーはステータスのツールチップで確認できる。
