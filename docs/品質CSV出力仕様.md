# 品質CSV出力仕様

更新日: 2026-11-14
状態: 実装前の仕様決定。現行のCSV生成処理との差分は末尾に記す。

## 目的と出力操作

主画面の「ファイル」メニューから、品質グラフの元データを次の2種類のCSVとして保存する。いずれも1行目を列見出しとし、Excelで読み込んで数値列をグラフの軸に指定できる表とする。

- **フレームCSV**：横軸を時刻秒、縦軸を評価値とする散布図・折れ線グラフ用。1行は「比較動画×指標×評価済みフレーム」。複数動画・複数指標はフィルターやピボットテーブルで分けられる縦持ち形式とする。
- **ファイルCSV**：横軸をビットレートkbps、縦軸をVMAF・SSIM・PSNRの平均値とする散布図用。1行は比較動画1本。指標ごとの列を設け、未評価の指標は空欄とする。

出力対象は、現在の元動画に対して正常終了した評価結果を1件以上持つ比較動画とする。画面上の動画選択や指標タブには絞られず、一覧に残る全比較動画・全完了指標を対象とする。行順は現在の一覧順、指標順はVMAF・SSIM・PSNR、フレーム順は番号昇順とする。評価結果が1件もない種類の出力は保存操作を受け付けず、理由を表示する。評価中でも既に完了した結果だけを対象にする。

## 列定義

| フレームCSV列 | 内容 |
| --- | --- |
| 比較動画番号 | 出力時の一覧順で振る1始まりの番号。同名ファイルの区別に使用 |
| 元動画名 | 元動画のファイル名。フルパスは出さない |
| 比較動画名 | 比較動画のファイル名。フルパスは出さない |
| グループ | 現在のグループ名。未設定は空欄 |
| 指標 | `VMAF`、`SSIM`、`PSNR` のいずれか |
| フレーム番号 | 評価対象の0始まりのフレーム番号。欠番は詰めない |
| 時刻秒 | フレーム番号 ÷ 評価対象の平均fps。現行のCFR対象範囲での換算時刻 |
| 評価値 | その指標の有限な評価値。SSIMは`All`、PSNRは`psnr_avg`、VMAFは`vmaf` |

| ファイルCSV列 | 内容 |
| --- | --- |
| 比較動画番号、元動画名、比較動画名、グループ | フレームCSVと同じ |
| 幅、高さ、fps、長さ秒 | 比較動画の取得済みメタデータ。fpsは平均fps |
| ビットレートkbps | グラフと共通の値。映像ストリーム、コンテナー、ファイルサイズ÷長さの順で採用したbpsを1000で割る。算出不能なら空欄 |
| ビットレート取得元 | `映像ストリーム`、`コンテナー`、`ファイルサイズ換算`、または空欄 |
| VMAF、SSIM、PSNR | 正常終了した結果の平均値。未評価は空欄 |

ビットレートには音声・コンテナー分を含む値が混在し得るため、取得元を列に残す。サイズ換算値を映像ストリームの実測値として表記しない。VMAFの平均はFFmpegの`pooled_metrics.vmaf.mean`、SSIM・PSNRの平均は保存対象の有限フレーム値の算術平均を使い、画面の値と一致させる。無限大のPSNRは現行の評価処理と同じく集計・フレーム出力から除く。

## CSV書式と内部データ

- UTF-8 BOM付き、カンマ区切り、CRLF改行。見出しは1行だけで、説明行や単位行を混ぜない。
- 数値は小数点を`.`とし、桁区切り・単位記号・引用符を付けない。不明値と未評価値は空欄とし、`0`や`未測定`で代用しない。
- 文字列はRFC 4180に沿って引用符で囲み、内部の引用符を二重化する。改行やカンマを含むファイル名・グループ名も1セルに収める。Excelの数式として解釈される先頭文字を持つ外部由来の文字列は、セル内容を文字列として扱わせる対策を入れる。
- 出力対象を保存開始時にスナップショット化する。内部では動画ID・指標をキーにした完了結果を維持し、CSV専用の行データへ変換してから書き出す。表示用の3桁区切り文字列をCSVへ流用しない。
- ビットレートの値と取得元はFFprobe取得時に保持する。フレーム時刻は現行の平均fps換算を明示して使う。VFR対応時には実PTSを別途保持し、この列を実時刻へ切り替える際に仕様と見出しを更新する。
- 書き込み失敗や中断で壊れた完成ファイルを残さないよう、一時ファイルを使って保存を確定する。元のFFmpegログはCSVに直接流用せず、解析済みの同じ評価結果からグラフとCSVを作る。

例（フレームCSV）:

```csv
比較動画番号,元動画名,比較動画名,グループ,指標,フレーム番号,時刻秒,評価値
1,"original.mkv","encode_A.mkv","設定A",SSIM,0,0,0.982
1,"original.mkv","encode_A.mkv","設定A",SSIM,1,0.03333333333333333,0.975
```

例（ファイルCSV）:

```csv
比較動画番号,元動画名,比較動画名,グループ,幅,高さ,fps,長さ秒,ビットレートkbps,ビットレート取得元,VMAF,SSIM,PSNR
1,"original.mkv","encode_A.mkv","設定A",1920,1080,30,60,2450.5,"映像ストリーム",,0.978,
```

## 実装時の確認

- 専用テスト画面で、複数動画・複数指標・未評価・同名動画・グループ・引用符等を含む名前の保存と読み戻しを確認してから主画面へ組み込む。
- Excelへの読み込みで時刻秒・ビットレートkbps・評価値が数値セルとなり、各CSVから想定したグラフを作れることを確認する。
- グラフの軸値とCSVの値、評価結果の平均値とCSVの値を照合する。既存MSTestと主画面の自動確認を実行する。

## 現行実装から変更する点

現行の`QualityCsvExporter`は2種類のCSVを作るが、主画面のメニューは無効。ファイルCSVには未評価動画も含み、グループ・元動画名・ビットレート取得元を出さず、サイズ換算値を3桁区切り文字列にしている。フレームCSVもグループ・元動画名・比較動画番号を出さない。現行グラフのサイズ換算フォールバックはkbpsへの換算係数がCSVと異なるため、実装時に共通の算出処理へそろえる。
