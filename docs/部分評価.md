# 部分評価

更新日：2026-11-15

## 通常画面での操作

1. 元動画と比較動画を登録する。
2. 一覧下の「評価範囲を設定」を開く。初期状態は全編評価。
3. 「部分評価を使用する」を有効にし、時間範囲指定・周期的な区間指定・全体に均等配置のカードから方式を選ぶ。
4. 入力に連動するバー・対象フレーム数を確認して「適用」する。無効な設定は適用できない。「キャンセル」では現在の評価条件を変更しない。
5. 通常画面で指標と対象動画を選び「評価を開始」する。動画を選択していない場合は全比較動画を対象とする。実行中は同じボタンで中止でき、範囲設定は変更できない。

全編へ戻すには「部分評価を使用する」を解除して適用する。設定カード・入力連動バーは専用テスト画面と共通の部品を使う。各方式の区間規則と表示形式は[部分評価テスト画面](部分評価テスト画面.md)を参照。

## 結果の扱い

- 動画・指標に加えて評価方式と数値設定で結果を分ける。同じ条件に戻すと、その条件の完了済み結果を復元する。
- 一覧・グラフ・CSVは現在の条件の結果だけを対象とする。別条件の結果で未評価の動画・指標を補わない。
- 部分評価の平均は評価対象だけの値。通常画面の評価設定欄に条件と「対象部分のみの平均」を表示する。
- 評価結果は起動中のメモリ内で保持する。元動画変更では全条件の結果を破棄し、比較動画削除ではその動画の全条件の結果を削除する。「評価クリア」は非表示の条件を含む全結果を削除する。
- 設定値が異なる場合は、偶然同じフレーム範囲になっても別条件として扱う。追加評価・途中結果との合成は行わない。

## グラフとCSV

- 元動画上のフレーム番号・時刻を保持する。部分評価のフレームグラフは動画全体の時間軸を使い、欠番の前後を線でつながない。
- ファイルグラフは評価対象だけの平均を使用する。点のツールチップに条件を表示する。
- グラフ画像も未評価区間を結ばず、部分評価であることを見出しに表示する。
- 部分評価を含むCSVには条件と集計フレーム数の列を追加する。詳細は[品質CSV出力仕様](品質CSV出力仕様.md)を参照。全編だけのCSVの列構成は維持する。
- 部分評価中の進捗時間は選択区間を連結した累計時間。元動画上の位置と誤認しないよう、グラフ上の処理位置表示には使用しない。

## 確認した範囲と制限

- 同解像度・同fpsのCFR動画が対象。元動画で定めた共通のフレーム範囲を比較動画へ適用する。比較動画の長さが不足する場合は評価できない旨を表示する。
- 区間外の復号も必要になるため、対象フレーム削減率と時間短縮率は一致しない。実動画での時間短縮率は未測定。
- VMAF・SSIM・PSNRの選択に対応する。今回の部分評価の実計算試験はSSIMで実施した。VMAFは選択区間を連結した入力を使うため、時間方向の処理を含む値と全編評価の一致は保証しない。PSNRの無限大は従来どおり集計対象外。
- 評価区間のみのスキップ再生、追加評価、起動間の条件・結果保存は未実装。
