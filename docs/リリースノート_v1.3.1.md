# VideoQualityAnalyzer v1.3.1 リリースノート

作成日：2026年11月20日

v1.3.0から、キーボード・マウス操作の追加とアプリアイコンの更新を行いました。

## 操作の追加

- プレビュー、再生UI、グラフにフォーカスがあるとき、Spaceで再生／一時停止、左右矢印で1秒、Shift＋左右矢印で5秒、Ctrl＋左右矢印で1コマ移動できます。
- Ctrl+Mでミュート切り替え、Ctrl+Oで動画ファイル追加ができます。基準動画または比較動画の一覧にフォーカスがあるときだけ、Delで選択動画を削除できます。
- シークバーとフレームグラフ上のホイールで0.2秒、Shift＋ホイールで1秒、Ctrl＋ホイールで1コマ移動できます。音量バー上のホイールは5%ずつ変更します。
- 比較プレビューのCtrl＋ホイールで表示倍率を10%ずつ変更できます。ワイプ映像のShift＋左クリック／ドラッグで境界を動かせます。

## 表示

- 2画面比較と、ワイプ・差分ヒートマップを表すアプリアイコンに変更しました。

## 確認範囲

- ショートカット専用画面と主画面の自動確認、比較操作6組、既存MSTestを実行しました。実キーボード・マウスによる入力と、ホイール拡大後の見た目は未確認です。
- 比較表示は同解像度・同フレームレートのCFR動画を対象とし、評価結果は起動中だけ保持します。その他の制限は[v1.3.0のリリースノート](リリースノート_v1.3.0.md)を参照してください。
