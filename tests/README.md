# コマンドによる自動テスト

MSTest 4.0.2を導入。画面認識・マウス操作・動画素材なしで実行する。

## 実行

リポジトリ直下で以下を実行する。初回はNuGetへの接続が必要。

```powershell
.\tests\Run-Tests.ps1
```

取得済みパッケージでの実行:

```powershell
.\tests\Run-Tests.ps1 -NoRestore
```

終了コード0は合格、それ以外は失敗。スクリプトは新しいTRXの作成と、1件以上の実行・全件合格も確認する。詳細はコンソールと`VideoQualityAnalyzer.Tests/TestResults`のTRXに出力する。
テスト用NuGet.Configだけでnuget.orgを有効にし、通常アプリの取得先設定は維持している。

## 対象

- 空の動画一覧、基準動画・比較動画の選択、直前の右動画維持、不正なID、世代番号の引き渡し。
- 診断ログの終了時書き出し、実行ID、性能値、提示fpsの未測定記録。

既存のSmokeとMediaFoundationProbeは引き続き素材・デコード検証に使用する。
今回のテストは実際の再生、非同期競合、左右同期精度、音声消音、GPU提示、実提示fps、画面レイアウトを検証しない。これらの達成を示すものではない。

## 検証記録（2026-10-30）

`Run-Tests.ps1 -NoRestore`で10件合格、失敗・スキップ0件。警告なし。Codexの制限付き実行ではテストが終了せず、制限外の実行で正常終了を確認した。停止対策として60秒のハング検出を設定している。
新しいテストはこのプロジェクトに追加し、AIは通常、終了コードと結果要約を確認する。失敗時に必要な詳細を読む。

## 完成版機能の確認（2026-11-03）

`tools/Run-FeatureChecks.ps1` でReleaseビルド、MSTest、3指標の実計算と中断、グループ設定画面、評価結果再利用とグラフ描画、主画面の選択維持・結果破棄・終了、比較画面6組の操作をまとめて確認する。比較試験には配置済み5本の動画と可視のWindowsデスクトップが必要。MSTestは22件。

品質評価の実計算は生成した64×64・30フレームのFFV1動画を使う。全動画・長時間の品質評価試験や、マウスによる画面操作・CSV保存ダイアログの目視試験を代替しない。追加の性能ベンチマークは実施しない。

## ファイル一覧とグラフの確認

2026-11-03の追加後はMSTest 25件。追加3件は数値昇降順・未評価値の末尾配置、ビットレート、VFR推定表示を確認する。
`--verify-evaluation` はSSIM初期選択・指標説明・タブ・横並び・点の選択連動を、`--verify-main-features` は表の情報列・評価列の昇降順・選択維持を確認する。`Run-FeatureChecks.ps1` の既存呼び出しに含まれる。

## 主画面の比較操作

`Run-FeatureChecks.ps1` の `--verify-main-comparison` は、主画面に埋め込んだ比較部品を6組で操作する。再生、タブ切り替え、一時停止保持、コマ送り、静止復号との画素一致、停止時の先頭保持、連続選択、1本表示への切り替えを確認する。音声同期・実提示fpsの計測ではない。

## 主画面の品質グラフ

`--verify-main-graphs` は検証用評価値を用い、再生制御下の配置、結果反映、ファイル点と一覧の選択連動、シーク、リセットを確認する。`tools/Run-FeatureChecks.ps1` に含まれる。検証用評価値は品質計算の正しさを判定するデータではなく、表示と操作の接続を確認するためのもの。

グラフ画像保存は `--test-graph-image --auto` で専用画面と本体用画面のプレビュー・PNG出力を確認する。`--verify-graph-image-save` に基準動画と比較動画のパスを続けると、主画面のファイルメニューから保存画面を開き、基準動画名・評価結果・選択を渡せることを確認する。

## シークバーの操作優先

`--verify-main-seek` は再生中・一時停止中のドラッグ位置保持、終了位置へのシーク、再生状態維持、連続要求、キー相当の値変更を確認する。実際の定期表示更新をまたいでバーの値が戻らないことを検査し、`Run-FeatureChecks.ps1` に含まれる。

## 主画面の評価開始・中止

`--verify-main-evaluation` は生成した赤・青の30フレーム動画を使い、一覧下のチェックと開始ボタン、処理中の中止ボタン、完了・再利用・中止、一覧とグラフへの反映、CSV機能の保持を実計算で確認する。`Run-FeatureChecks.ps1` に含まれる。

## 表示書式と確認用ビルド

主画面の評価試験でチェックの縦並びと共通フォントを、比較操作試験で2画面・ワイプ・差分ヒートマップのタブ順を確認する。
通常アプリが起動中で出力ファイルがロックされている場合は、`tools/Run-FeatureChecks.ps1 -OutputFolder ThemeVerification` で同じRelease構成を別フォルダーへビルドして確認できる。通常起動用ファイルへの反映は、アプリを閉じて通常のReleaseビルドを行う。
