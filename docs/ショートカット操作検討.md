# キーボード・マウス操作の検討

2026-11-20時点の初期案。キー、修飾キー＋マウス、ホイールの割り当ては未実装・未検証。

## 対象と現在の操作

- 完成版仕様書には再生・停止・シーク・前後1秒／5秒・1コマ移動などの操作があるが、ショートカットの規定はない。
- 主画面では再生ボタン、シークバー、フレームグラフ、動画一覧、比較タブ、音量バーを対象とする。範囲設定やグループ設定などのダイアログでは標準のTab・Space・Enter・Esc操作を維持する。
- 現在、主画面にアプリ共通のキー割り当てはない。グラフ境界のThumbにフォーカスがある場合だけ、上下矢印で高さを10ずつ変更する。シークバーなどの標準部品にも固有のキー操作がある。
- シークバーとフレームグラフはクリック・ドラッグで位置を指定する。動画一覧は複数選択でき、空白のクリックで選択を解除する。
- 比較プレビューの拡大時は映像の左ドラッグで左右同時に表示位置を動かす。ワイプ境界線の左ドラッグは境界位置を動かす。グラフ境界と一覧境界もドラッグでサイズを変える。
- ホイールの独自処理はない。スクロール領域や一覧では標準のホイール操作を優先する。

## キーボードの初期案

| 操作 | キー案 | 条件・理由 |
| --- | --- | --- |
| 再生／一時停止 | Space | プレビュー画面・再生UI・グラフ内にキーボードフォーカスがあるとき、再生／一時停止を優先する。一覧やその他の領域では各部品の標準操作を優先する。 |
| 停止して先頭へ戻る | なし | Ctrl+Shift+Sは一般的な「名前を付けて保存」と衝突するため避ける。停止ボタンは維持する。 |
| 1秒戻る／進む | Left／Right | プレビュー画面・再生UI・グラフ内にキーボードフォーカスがあるとき、共通の再生位置を移動する。 |
| 5秒戻る／進む | Shift+Left／Shift+Right | 同じフォーカス範囲で、1秒移動と対応させる。 |
| 1コマ戻る／進む | Ctrl+Left／Ctrl+Right | 同じフォーカス範囲で、既存の1コマ移動を呼ぶ。JIS配列とUS配列の両方で押しやすい。 |
| ミュート切り替え | Ctrl+M | 音量スライダーのキー操作とは分ける。 |
| 動画ファイルを追加 | Ctrl+O | ファイル選択画面を開く。 |
| 選択した動画を削除 | Del | 基準動画または比較動画の一覧内にキーボードフォーカスがある場合だけ実行する。複数選択を含み、未選択なら動作しない。削除対象と確認手順は既存の画面操作に合わせる。 |

評価開始／中止、評価クリア、CSV出力、グループ変更には初期段階でグローバルキーを割り当てない。

## 修飾キー＋マウスの初期案

| 場所 | 操作案 | 動作 | 競合・条件 |
| --- | --- | --- | --- |
| ワイプ映像 | Shift＋左クリック／ドラッグ | 映像上の位置へ境界線を移動し、ドラッグ中も追従する。 | 境界線上の通常ドラッグと、拡大時の通常ドラッグによる映像移動を維持する。 |
| 動画一覧 | Ctrl＋左クリック、Shift＋左クリック | 複数行の追加・範囲選択にDataGrid標準の動作を使う。 | アプリ独自の割り当ては追加しない。選択によるプレビュー更新は既存規則に従う。 |
| シークバー・フレームグラフ | 修飾キーなしのクリック／ドラッグ | 現行の位置指定を維持する。 | Ctrl／Shift付きクリックへの別の割り当ては保留する。 |

## ホイール操作の初期案

| ポインター位置と入力 | 動作案 | 再生・表示の扱い |
| --- | --- | --- |
| 動画表示領域でCtrl＋ホイール | 上で10%拡大、下で10%縮小する。 | 比較プレビューの既存倍率範囲10～300%に収め、左右・ヒートマップの倍率を同期する。ポインター位置を拡大中心とし、自動フィットからは画面に収めた倍率を基準にする。 |
| シークバー・フレームグラフでホイール | 上で0.2秒戻る、下で0.2秒進む。 | 再生中は再生状態を維持する。 |
| シークバー・フレームグラフでCtrl＋ホイール | 上で1コマ戻る、下で1コマ進む。 | 再生中は一時停止してからコマ移動する。 |
| シークバー・フレームグラフでShift＋ホイール | 上で1秒戻る、下で1秒進む。 | 再生中は再生状態を維持する。 |
| 音量バーでホイール | 上で5%上げ、下で5%下げる。 | 0～100%に収める。ミュート状態の扱いは検証時に決める。 |
| 一覧、グラフの凡例、ダイアログのスクロール領域、上記以外のスライダー | その部品の標準動作を優先する。 | 動画の倍率や再生位置へ転送しない。 |

拡大した動画表示領域での修飾キーなしのホイールは、既存スクロール領域の縦移動を維持する。動画表示領域のShift＋ホイールには新しい操作を割り当てない。

## 入力の優先順位と未決定事項

1. SpaceとLeft／Right（Shift・Ctrlとの組み合わせを含む）は、プレビュー画面・再生UI・グラフ内にキーボードフォーカスがあるとき、共通の再生操作を優先する。上下矢印には割り当てない。一覧にフォーカスがあるときは一覧の標準操作を優先する。Delは基準動画・比較動画のいずれかの一覧内にフォーカスがあるときだけ有効にする。
2. ダイアログ、メニュー、文字入力、IMEによる日本語入力中は、その入力を優先する。対象領域内のコンボボックス、スライダー、チェックボックス、タブ、ボタンと再生操作の競合は専用画面で確認する。シークバー・音量バーのホイール案も同じ画面で確認する。
3. ポインターが対象領域上にある場合だけ、その領域のマウス操作とホイール操作を実行する。対象外や無効状態では例外や状態変更を発生させない。
4. 通常プレビューと比較表示で同じ再生操作を使い、左右の共通時刻と「評価した部分のみ再生」の区間制約を維持する。連続シークでは最後の要求位置を優先する。
5. 高精度ホイールの小さな差分をどう蓄積するか、1回の操作とみなす量、拡大中心の表示位置保持、音量変更時のミュート状態は検証して決める。
6. 通常の2画面プレビューと比較表示で拡大機能の対応範囲が異なる場合、未対応の表示領域では操作を無効にし、案内を統一する。

## 検証の進め方

1. 専用テスト画面でキー・修飾キー・ポインター位置・ホイール方向を判定する。プレビュー画面・再生UI・グラフ・両一覧・その他の領域へフォーカスを移し、Space・左右矢印・Delの有効範囲を確認する。文字入力、シークバー、グラフ境界、比較タブ、IME入力中などの標準操作との優先順位も確認する。
2. 再生・一時停止・停止・秒移動・コマ送りを通常プレビューと比較表示の両方で確認する。ホイールによる0.2秒・1秒移動とコマ送り、音量5%、倍率10～300%の端、高精度ホイール・連続入力を確認する。
3. 2画面・ワイプ・差分ヒートマップの対応する表示で、ワイプ境界と映像移動の優先順位、倍率と表示位置の同期を確認する。再生中・一時停止中の両方で、意図しない再生状態や時刻の変更がないことを確かめる。
4. 専用画面で正常動作を確認してから主画面へ組み込み、確定した操作だけツールチップとメニューに表示する。自動確認と実際のキー・マウス操作で確認した範囲を分けて記録する。
