# Video Quality Analyzer Tool 仕様書

> 旧Python版の参考資料です。本文の「現行」は旧Python版を指します。C#・WPF版の方針は[完成版仕様書](../CSharp_WPF_仕様書.md)を参照してください。

更新日: 2026-10-27  
対象: 現行実装（`pyproject.toml` のバージョン 0.1.0）

## 1. 目的と適用範囲

Windows 上で、1 本の元動画と複数のエンコード済み動画を比較するデスクトップツール。品質指標、ビットレート、フレームごとの変化を確認し、結果を CSV に出力する。

本書は**現行コードで利用できる機能**を記述する。過去のチャットにある構想のうち、未実装のものは「9. 未実装・制約」に分けた。画面の細かな実装方法は [詳細設計書](詳細設計書.md) を参照する。

## 2. 動作環境

| 項目 | 仕様 |
| --- | --- |
| OS | Windows 向け。開発版は Python 3.11 以上を使用 |
| 画面 | Tkinter / ttk。ドラッグ＆ドロップは `tkinterdnd2` が利用できる場合に有効 |
| 品質評価 | FFmpeg。動画情報取得は FFprobe。VMAF には `libvmaf` 対応ビルドが必要 |
| プレビュー | OpenCV による映像フレーム読み取り、Pillow による表示 |
| 音声 | FFmpeg で一時的な OGG 音声へ変換し、pygame で再生 |
| グラフ | Matplotlib |
| 配布 | PyInstaller による Windows 用フォルダーと ZIP。FFmpeg 本体は同梱しない |

## 3. 基本操作

1. 「動画ファイルを追加」または比較動画一覧へのドラッグ＆ドロップで動画を登録する。複数ファイルを一度に選べる。最初に登録された動画は自動的に元動画になる。
2. 必要に応じて、比較動画一覧の 1 本を選択して「▲ 元動画に設定」を押すか、元動画欄へドラッグして元動画を変更する。
3. 比較動画と評価指標（VMAF、SSIM、PSNR）を選び、「選択動画を評価」を押す。評価中は同じボタンで中断できる。
4. プレビューと指標別グラフで結果を確認する。必要に応じて「ファイル → CSVを出力」から保存する。

## 4. 動画一覧と元動画

- 元動画は専用欄に表示し、品質評価の対象から外す。比較動画一覧には元動画以外を表示する。登録情報はアプリ終了後に復元しない。
- 比較動画一覧では複数選択できる。一覧の見出しから動画名、グループ、ビットレート、各指標の平均値で並べ替えられる。同じグループのグラフ上の線は、その時点の一覧順で点を結ぶ。
- 同じパスの動画を重複登録しない。動画情報は画面を止めない作業スレッドで読み込む。情報取得に失敗した動画は登録せず、警告を表示する。
- 元動画の変更または削除時には、元動画に依存する既存の評価結果を破棄する。評価中は動画の追加、除去、元動画変更、一覧クリアを行えない。
- 一覧に残った動画ファイルが外部で削除されていた場合、選択時に存在しない旨を表示し、一覧から除去するか確認する。除去しない場合はプレビュー対象から外す。
- 元動画と解像度またはフレームレートが異なる動画があれば警告する。自動的なサイズ・フレームレート変換はしない。

## 5. グループ

- 1 本の比較動画が所属できるグループは 1 つ。複数の比較動画を選択して一括設定できる。
- グループ名を空欄にした動画は、表示名が空欄のグループとして扱う。
- グループは実行中のメモリだけに保持し、次回起動時には復元しない。
- 平均品質対ビットレートのグラフでは、同じグループの点を一覧順に結び、別グループの点は結ばない。動画ごとに点色を変え、名前付きグループ内では同系色を使う。左側のフレーム推移グラフも同じ動画の点色に合わせる。

## 6. 品質評価

- 選択可能な指標は VMAF、SSIM、PSNR。初期状態では VMAF のみが選択される。少なくとも 1 本の比較動画と 1 つの指標、および元動画が必要。
- 比較する 2 本の動画はそれぞれ先頭を時刻 0 として FFmpeg に渡す。評価範囲は両動画の共通部分とする。
- 選択した動画・指標の組み合わせで完了済みの結果は再計算しない。未完了の組み合わせだけ実行する。
- 評価中は進捗とフレームごとの途中結果を表示する。中断または失敗した組み合わせの途中結果は、完了済み結果として扱わない。完了済みの別の組み合わせは残る。
- 「評価をリセット」は確認後、全動画の評価結果を削除する。
- 解像度、フレームレート、色空間の自動補正は行わない。条件の異なる動画の評価値は、利用者が比較可能性を判断する。

## 7. プレビューとグラフ

### 7.1 プレビュー

- 「2画面表示」で最大 2 本を同じ時刻に表示する。初期表示は左が元動画、右が先頭の比較動画。比較動画を 1 本選ぶと右側へ表示し、2 本選ぶとその 2 本を左右へ表示する。選択解除後も直前の右側動画を維持する。
- 「ワイプ比較」「差分ヒートマップ」「点滅比較」はタブのみ存在し、比較表示は未実装。タブ内に未実装の案内を表示する。
- 再生・一時停止・停止、シークバー、前後 1 秒／5 秒移動、1 コマ移動、表示倍率、音量、ミュートを操作できる。停止は再生位置を先頭に戻す。
- 音声は左画面の動画から再生する。音声がない場合や音声装置が利用できない場合も映像プレビューは継続する。
- 操作中の応答性のため、表示対象の動画だけをプレビュー用に開き、対象から外れた動画は解放する。表示中の動画は一時的にファイルが使用中になる場合がある。
- 設定画面でプレビューのハードウェアデコードを切り替えられる。利用できない環境や動画では通常のデコードに切り替えて表示する。

### 7.2 グラフ

- 指標ごとのタブに、フレーム品質の時系列と、全評価済み比較動画の平均品質対ビットレートを表示する。
- 時系列グラフは一覧で選択した動画を描画する。平均値グラフは一覧の選択に関係なく評価済みの全比較動画を描画し、選択した動画の点を強調する。
- 時系列グラフのクリック・ドラッグでプレビューをシークできる。平均値グラフの点をクリックすると対応する動画を一覧で選択する。
- 可変フレームレート動画で取得できたフレーム時刻は、グラフ、CSV、コマ送りに使う。取得できない場合は平均フレームレートで時刻を近似する。
- グラフ文字サイズはグラフ領域の選択欄で変更でき、次回起動時に復元する。

## 8. メニュー、設定、出力

| メニュー | 主な機能 |
| --- | --- |
| ファイル | 新規作成、動画を追加、動画単位 CSV、フレーム単位 CSV、終了 |
| 評価 | 選択動画を評価／中断、評価結果をリセット |
| オプション | 設定、ログフォルダーを開く |
| ヘルプ | 操作説明、バージョン情報 |

- 新規作成は、動画が登録されている場合に確認してから一覧、評価結果、再生位置を初期化する。評価中の終了は、中断して終了するか確認する。
- 設定画面では「前回の設定を読み込む」（評価指標のチェック状態）、画面フォント、グラフフォント、FFmpeg 解凍先、プレビューのハードウェアデコードを指定する。グラフ文字サイズはグラフ画面側で変更する。
- FFmpeg 解凍先を明示した場合、直下の `bin/ffmpeg.exe` と `bin/ffprobe.exe` が必要。指定解除時はアプリ内の既定候補、開発用候補、システム `PATH` から自動検出する。
- 設定はアプリと同じ場所の `settings.json` に保存する。動画一覧、評価結果、グループは保存しない。
- 動画単位 CSV は、動画ごとのファイル名、寸法、fps、長さ、ビットレート、ファイルサイズ、3 指標の平均値を出力する。未評価の平均値は空欄。
- フレーム単位 CSV は、評価結果がある動画についてファイル名、指標、フレーム番号、時刻、評価値を出力する。両 CSV とも UTF-8 BOM 付き。
- 診断ログは `%LOCALAPPDATA%/VideoQualityAnalyzerTool/logs/application.log` に保存する。2 MiB ごとにローテーションし、現行ファイルとバックアップ 4 個を保持する。
